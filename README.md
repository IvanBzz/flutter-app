# Расписание Финуниверситета

Самостоятельное Flutter-приложение для работы с открытым API `ruz.fa.ru`.

## Возможности

- поиск групп и преподавателей через `/api/search`;
- загрузка расписания через `/api/schedule/{group|person}/{id}`;
- просмотр расписания списком, недельной сеткой и аналитикой;
- переход по неделям назад и вперед;
- карточка деталей занятия: аудитория, корпус, преподаватель, группа, примечание и онлайн-ссылка;
- избранное и недавно открытые элементы в рамках текущего запуска;
- локальный proxy-сервер для web-демо, чтобы браузер не упирался в CORS.

Код приложения написан заново: собственные модели, API-клиент, состояние, экраны и календарная сетка. Учебные примеры из исходного репозитория не импортируются.

## Запуск для показа в браузере

В одном терминале:

```bash
dart run bin/proxy_server.dart
```

Во втором терминале:

```bash
flutter pub get
flutter run -d edge --web-port 51741
```

Откройте:

```text
http://localhost:51741
```

Для проверки можно ввести `ПИ22` и открыть группу `ПИ22-1`.

## Запуск как Windows-приложение

```bash
flutter pub get
flutter run -d windows
```

Для Windows-сборки нужен установленный Visual Studio C++ toolchain.

## Проверка

```bash
flutter analyze
flutter test

```
