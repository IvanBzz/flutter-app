# Расписание ФА

Готовое Flutter-приложение для просмотра расписания Финансового университета через API `ruz.fa.ru`.

## Что умеет приложение

- Ищет группы и преподавателей через `/api/search`.
- Показывает список найденных групп или преподавателей.
- Открывает расписание выбранного элемента через `/api/schedule/{group|person}/{id}`.
- Показывает расписание за выбранную неделю.
- Переключает представление расписания: список занятий или календарная таблица.
- Поддерживает прямой доступ к `https://ruz.fa.ru/api` и прокси `http://localhost:3000`.

## Запуск

Из папки `2.flutter/furshed`:

```bash
flutter pub get
flutter run -d windows
```

Если прямые запросы к `ruz.fa.ru` не проходят, запустите прокси из корня `2.flutter`:

```bash
dart run first/flutter_application_1/server.dart
```

После этого включите переключатель прокси в правом верхнем углу приложения.

## Проверка

```bash
flutter test
```

## Использованные этапы

Приложение объединяет идеи из учебных примеров: stateful-виджеты, загрузку данных по API, поиск, передачу выбранных данных между экранами и календарный виджет `time_scheduler_table`.
